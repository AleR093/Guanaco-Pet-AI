# GuanacoPet AI 🇸🇻 - Guía de Desarrollo

## Nombre del Proyecto
**GuanacoPet AI** (Transformaciones cómicas con IA para mascotas en El Salvador).

## Contexto del Proyecto
Aplicación web para transformar fotos de mascotas (chuchos y mishis) en versiones divertidas y locales salvadoreñas utilizando IA.

## Stack Tecnológico
- Next.js (App Router, carpeta `src/app`)
- Tailwind CSS para estilos rápidos y responsivos (Mobile-First)
- TypeScript estricto
- Lucide React para iconografía

## Reglas de Diseño & UX
- Tono: Divertido, amigable, con jerga salvadoreña (ej. "¡Transformá a tu bicho!", "Modo Guanaco", "Chuchos y Mishis").
- UI: Colores vibrantes (Azul El Salvador #0047AB, detalles en dorado/amarillo, interfaz limpia y moderna).
- Pensado 100% para celulares (tráfico proveniente de Instagram/Facebook Ads).

## Estructura de Flujo
1. Header con branding **GuanacoPet AI 🇸🇻**.
2. Hero con llamada a la acción.
3. UploadZone: Subida de foto (drag & drop o selector).
4. StyleSelector: Selector de estilos locales (Prócer, Cumbiero, Don Pupusero, Bicho de Colonia, Superhéroe SV).
5. CheckoutModal: Simulación de pago rápido.

## Requerimientos Clave (Actualización)
- **Modo Oscuro Obligatorio:** Toda la aplicación debe tener diseño oscuro por defecto (fondos grises oscuros/negros, textos claros, acentos vibrantes) para evitar fatiga visual.
- **Modelo de Negocio (Enmarcado Físico):** La transformación de la IA es gratuita como "gancho". Lo que se cobra es el servicio de impresión y enmarcado físico con tarifas adaptadas al mercado salvadoreño según el tamaño del cuadro.
